  Система автофокусировки для профессиональной камеры

Проект автоматизированной системы фокусировки объектива профессиональной камеры. Система измеряет расстояние до объекта и с помощью двигателя автоматически устанавливает кольцо фокусировки в необходимое положение. 

  Основные задачи

- измерение расстояния до объекта;
- управление двигателем фокусировки;
- автоматическая калибровка;
- разработка электрической схемы и программирование контроллера;
- сборка и тестирование прототипа.
